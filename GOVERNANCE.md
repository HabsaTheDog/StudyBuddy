# Governance

Study Buddy currently uses a maintainer-led governance model. Alvaro Schroll
(`@HabsaTheDog`) is the project maintainer and final decision maker for releases,
security response, roadmap, permissions, and architecture.

Routine fixes can be accepted through normal review. Changes affecting
authentication, privacy, analytics, student data, network behavior, quiz or
assignment permissions, the Study Builder charter, or release infrastructure
require explicit maintainer approval and a written design record.

Decisions should favor student safety, source grounding, local data ownership,
reproducibility, and a small maintainable scope. The maintainer may delegate
areas to recurring contributors and update this document as the community
grows. No response or merge-time SLA is promised.

Security embargoes and personal-data incidents are handled privately. Other
material project decisions should be summarized in public issues, pull requests,
or design documents so contributors can understand the reasoning.
