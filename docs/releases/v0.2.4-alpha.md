# Study Buddy v0.2.4-alpha

This alpha combines the accumulated desktop and study workflow improvements
since 0.2.2-alpha. Alpha versions may contain defects and breaking changes.
Website availability is a separate approval of the exact downloadable bytes.

## Changes

- Install and connect Codex, Gemini or Claude, and choose task profiles for your
  configured providers. Live provider availability still depends on your account.
- Discover configured study evidence, weekly obligations and course context more
  reliably, including source-grounded recipients and session details for drafts.
- Generate PDF study guides through one native document owner with deterministic
  template preparation, original source attribution and clearer mathematical
  formatting. PDF tooling is documented in the setup guide.
- Capture complete native quizzes and original media, recover the authorized
  first attempt, and verify saved responses. Saved-response verification does
  not guarantee mathematical correctness. Final Moodle submission is blocked.
- Use permission-bound email inventory, search and read operations; approve an
  exact message before sending. Latest unread requests preserve read state and
  use provider ordering instead of reading many bodies to sort them.
- Improved chat, sidebar, composer, profile controls, voice titles, telemetry
  consent, desktop isolation, updater diagnostics and local browser pairing.
- Updated security dependencies and Windows runtime/test portability.

## Downloads and installation

- `Study-Buddy-0.2.4-alpha-x64.exe`: Windows 11 x64 NSIS installer.
- `Study-Buddy-0.2.4-alpha-x86_64.AppImage`: Fedora x64 AppImage.

macOS and other architectures are unsupported. Download only from the
[official website](https://studybuddy.habsa.at/) or this GitHub Release.
Compare the installer hash against `SHA256SUMS` before launching:

```powershell
Get-FileHash .\Study-Buddy-0.2.4-alpha-x64.exe -Algorithm SHA256
```

```bash
sha256sum Study-Buddy-0.2.4-alpha-x86_64.AppImage
chmod u+x Study-Buddy-0.2.4-alpha-x86_64.AppImage
./Study-Buddy-0.2.4-alpha-x86_64.AppImage
```

Windows is intentionally unsigned: expect **Unknown publisher** or SmartScreen
warnings. Verify the official source and checksum; never disable SmartScreen
globally. Existing users can install the newer version over their prior alpha;
release acceptance must separately verify updater behavior and retained state.

## Privacy and limitations

Source credentials remain local and are resolved only for authorized provider
operations. Prompts and selected context can be sent to your model provider.
Usage analytics and conversation sharing remain separate opt-in controls.
Review [privacy](https://github.com/HabsaTheDog/StudyBuddy/blob/master/PRIVACY.md)
and [security](https://github.com/HabsaTheDog/StudyBuddy/blob/master/SECURITY.md)
before connecting private sources.

- Native development acceptance does not establish universal provider, course or
  quiz correctness. Official grading and model output can differ.
- Live Claude subscription behavior, other email providers and concurrent
  cross-process email registry writes are not covered by existing development
  acceptance. PDF/Office tooling has separate setup requirements.
- Windows is unsigned; macOS is unavailable. GitHub source archives omit the UI
  submodule; developers must clone with `--recurse-submodules`.

Report problems through [support](https://github.com/HabsaTheDog/StudyBuddy/blob/master/SUPPORT.md)
or [issues](https://github.com/HabsaTheDog/StudyBuddy/issues). Follow the
[security policy](https://github.com/HabsaTheDog/StudyBuddy/security/policy)
for private security reports.

Candidate publication, distribution promotion and claimed packaged acceptance
remain pending until the exact release readiness record has a GO decision.
