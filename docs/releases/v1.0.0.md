# Study Buddy v1.0.0

Study Buddy 1.0 is the first stable desktop release of the local-first,
source-grounded learning companion. It ships for Linux x64 and Windows x64.

## Highlights

- Connect Moodle courses, ordinary websites/resource portals, calendars, and
  email accounts through one governed source inventory.
- Start onboarding with no preselected sources, then add, edit, disable, or
  remove as many sources as needed.
- Generate source-grounded answers, validated PDF study guides, and portable
  offline interactive learning pages.
- Keep consequential quiz and assignment actions review-gated; final Moodle quiz
  submission remains blocked.
- Receive an in-app notification when a newer GitHub Release is available and
  choose when to download and restart.
- Keep usage analytics and conversation sharing as separate opt-in controls that
  both start disabled.

## Supported downloads

- `Study-Buddy-1.0.0-x64.exe` — Windows 11 x64 NSIS installer
- `Study-Buddy-1.0.0-x86_64.AppImage` — Fedora/Linux x64 AppImage

macOS is not supported in version 1.0. Source archives do not contain submodule
contents; developers should clone with `--recurse-submodules` instead.

## Windows trust warning

The Windows installer is intentionally unsigned because the project does not
yet have a trusted code-signing service. Windows can therefore display
SmartScreen or **Unknown publisher**. Download only from this GitHub Release,
verify the SHA-256 checksum, and never disable SmartScreen globally. This
limitation affects publisher verification; it does not replace the attached
hashes and immutable build provenance.

```powershell
Get-FileHash .\Study-Buddy-1.0.0-x64.exe -Algorithm SHA256
```

## Linux launch

```bash
sha256sum Study-Buddy-1.0.0-x86_64.AppImage
chmod u+x Study-Buddy-1.0.0-x86_64.AppImage
./Study-Buddy-1.0.0-x86_64.AppImage
```

Compare the result with the matching entry in `SHA256SUMS` before launching.

## Runtime requirements

Study Buddy bundles its JavaScript/Codex runtime; Windows does not require Node,
Git Bash, or WSL. Browser-backed sources use an installed Edge, Chrome, or
Chromium. Typst is required only for PDF generation, Poppler enables complete
PDF extraction, and LibreOffice enables optional Office-document conversion.
Offline HTML learning pages do not require those document tools.

## Privacy and credentials

Portal credentials and private source links stay on the device. The two optional
sharing categories are described in [PRIVACY.md](../../PRIVACY.md) and can be
disabled independently. Model requests can still send the prompt and selected
source context to the configured model provider; review that provider's terms
before using private course material.

## Known limitations

- Windows publisher identity is not code-signed yet.
- macOS binaries and automatic updates are not available.
- Generic Moodle and web sources are supported, while CIS/calendar behavior is
  currently tailored to FH Technikum Wien.
- Browser-backed sources depend on a compatible installed system browser.
- PDF generation and complete PDF/Office ingestion depend on the separately
  installed document tools listed above.
- Authenticated model use requires the user's own supported Codex/provider
  access and may incur provider costs.

The release bundle also contains updater manifests, platform and root CycloneDX
SBOMs, `release-manifest.json`, the Windows blockmap (the Linux blockmap is
embedded in the AppImage), and `SHA256SUMS`. Report suspected
security issues privately as described in [SECURITY.md](../../SECURITY.md).
