# Study Buddy v0.1.0-alpha.5

This corrective alpha focuses on clean-machine reliability, source management,
desktop identity, and release security. It remains intended for technical
evaluation; breaking changes are still possible.

## What changed

- Fresh onboarding starts with no preselected sources and a prominent add-source
  action. Users can add more than three sources and edit, disable, or delete
  them individually.
- Source credential fields remain write-only in the interface and no longer
  trigger a React input failure when an existing source is edited.
- Packaged configuration writes now use Study Buddy's private application-state
  root instead of attempting to modify installed program files.
- Clean Windows and Linux installations can bootstrap the official standalone
  Codex runtime without requiring a developer checkout.
- Local-only desktop startup probes only the IPv4 loopback interface, avoiding
  an unnecessary Windows Defender Firewall request. Network exposure remains an
  explicit user-controlled mode.
- Windows installer, executable, shortcut, taskbar, and window assets use the
  Study Buddy name and icon.
- Prerelease updates remain eligible for newer alphas while refusing same-version
  offers and automatic downgrades to an older alpha.
- The release pipeline verifies an exact public UI commit, checksums every
  downloadable file, emits CycloneDX SBOMs, and fails closed for unavailable
  signing modes.

## Security and privacy

Study Buddy keeps source passwords and private links on the device and stores
protected values through the operating-system credential facility. Usage
analytics are optional and separate from conversation sharing. Never attach
private course data, credentials, or diagnostic logs containing personal data
to a public issue.

The Windows build is intentionally unsigned. Download it only from this GitHub
release, verify its SHA-256 against the attached `SHA256SUMS`, and expect Windows
to display an **Unknown publisher** or SmartScreen warning. Do not disable
SmartScreen globally or bypass an organization-managed policy.

## Known limitations

- macOS is not shipped.
- Windows code signing is not yet available.
- A representative generated workflow requires the user's own authorized Codex
  account; synthetic release-lab credentials do not validate model execution.
- Authenticated Moodle, CIS, calendar, and email acceptance remains
  maintainer-only and must use explicitly authorized accounts.
- This alpha supports Linux x64 and Windows x64. Other architectures are not
  included in the release bundle.

## Update or install

Existing alpha installations can use Study Buddy's in-app update notification
after this prerelease is public. A manual installation over an older alpha is
intended to preserve local application state.

On Windows PowerShell:

```powershell
Get-FileHash .\Study-Buddy-0.1.0-alpha.5-x64.exe -Algorithm SHA256
```

Uninstall through **Settings → Apps → Installed apps → Study Buddy**. The
uninstaller retains local Study Buddy state and the separately installed Codex
runtime to avoid accidental data loss.

On Linux:

```bash
sha256sum Study-Buddy-0.1.0-alpha.5-x86_64.AppImage
chmod u+x Study-Buddy-0.1.0-alpha.5-x86_64.AppImage
./Study-Buddy-0.1.0-alpha.5-x86_64.AppImage
```

GitHub-generated source archives omit submodule contents. Clone recursively for
a source installation:

```bash
git clone --recurse-submodules https://github.com/HabsaTheDog/StudyBuddy.git
cd StudyBuddy
npm ci
```
