# Study Buddy v0.2.5-alpha

This hotfix corrects provider setup when a supported Codex or Claude CLI is
already installed. Study Buddy should recognize the existing executable and
show its connection state without asking you to reinstall it unnecessarily.
Provider discovery, version checks and refresh use consistent resolution across
Windows and Fedora. Authentication remains separate from installation; an
installed CLI may still need you to sign in.

This candidate retains the features and security fixes shipped in 0.2.4-alpha.
It is a GitHub prerelease. Exact-candidate source and packaged acceptance are
pending; publication and website promotion follow those checks.

## Downloads and setup

Supported platforms: **Windows 11 x64** and **Fedora x64**. macOS, other operating
systems and other architectures are unsupported.

- `Study-Buddy-0.2.5-alpha-x64.exe`: Windows installer.
- `Study-Buddy-0.2.5-alpha-x86_64.AppImage`: Fedora AppImage.

Use the [official GitHub releases](https://github.com/HabsaTheDog/StudyBuddy/releases)
or [official website](https://studybuddy.habsa.at/). Compare the downloaded
installer with the release's `SHA256SUMS` before launching:

```powershell
Get-FileHash .\Study-Buddy-0.2.5-alpha-x64.exe -Algorithm SHA256
```

```bash
sha256sum Study-Buddy-0.2.5-alpha-x86_64.AppImage
chmod u+x Study-Buddy-0.2.5-alpha-x86_64.AppImage
./Study-Buddy-0.2.5-alpha-x86_64.AppImage
```

Windows is intentionally unsigned: expect **Unknown publisher** or SmartScreen
warnings. Verify the official source and checksum; never disable SmartScreen
globally. Existing users can install over their earlier alpha.

The desktop includes its JavaScript runtime. Browser-backed sources require
installed Edge, Chrome or Chromium. PDF output requires Typst and Poppler:
`typst`, `pdfinfo`, `pdftotext` and `pdftoppm` must be on the application PATH.
The current doctor omits `pdfinfo`; verify all four before requesting a PDF.
LibreOffice is needed only for optional Office-document conversion.

## Privacy and limitations

Source credentials remain local. Prompts and selected context can be sent to
your configured model provider. Usage analytics and conversation sharing remain
separate opt-in controls. Read [privacy](https://github.com/HabsaTheDog/StudyBuddy/blob/master/PRIVACY.md)
before connecting private sources.

Alpha defects and breaking changes remain possible. Provider account availability
and authentication depend on the provider; live Claude subscription behavior
and arbitrary custom installations are not universally verified. Authenticated
packaged email compatibility remains outside this hotfix's acceptance scope.
Review generated answers and files. Final Moodle quiz submission remains blocked.

Report reproducible issues through [support](https://github.com/HabsaTheDog/StudyBuddy/blob/master/SUPPORT.md)
or [issues](https://github.com/HabsaTheDog/StudyBuddy/issues). Use the
[security policy](https://github.com/HabsaTheDog/StudyBuddy/security/policy)
for private vulnerability reports; never attach credentials or private source
material to a public report.
