# Study Buddy v0.1.0-alpha.3

This corrective alpha hardens the desktop updater and carries the Windows source
and application-identity fixes through the exact packaged release path. It is
still intended for technical evaluation; breaking changes remain possible.

## What changed

- The installed app now reports the release version embedded by the release
  workflow instead of falling back to an older development version.
- Alpha builds remain eligible for newer prereleases but never automatically
  downgrade to an older published alpha.
- Fresh onboarding starts with no selected sources and supports adding more than
  three sources, plus editing, disabling, and deleting them on Windows.
- The unsigned Windows installer, executable, shortcuts, taskbar, and app window
  use the Study Buddy identity and icon.
- The app can install the official standalone Codex runtime during onboarding.
- Optional usage analytics can be sent to the private Study Buddy PostHog service
  while conversation sharing stays disabled.

## Windows acceptance

The exact x64 installer from GitHub Actions run `32957438007` passed clean-VM
checks for artifact integrity, interactive installation, Study Buddy identity,
SmartScreen/Unknown publisher behavior, zero-source onboarding, Codex
installation, more-than-three source handling, edit/disable/delete, packaged
browser connectivity, network-failure messaging, restart persistence, optional
telemetry delivery, and uninstall retention.

The release remains unsigned. Verify the GitHub release URL and the selected
file's SHA-256 from `SHA256SUMS` before choosing **Run anyway**. Never disable
SmartScreen globally or circumvent a managed-device policy.

## Known limitations

- macOS is not shipped.
- Windows code signing is not yet available, so SmartScreen can warn or block
  the installer.
- The alpha.2-to-alpha.3 in-app updater transition can only be accepted after
  alpha.3 is available on the public prerelease channel.
- A representative generated workflow requires the user's own authorized Codex
  account. Synthetic release-lab credentials do not count as model acceptance.
- FH Technikum and other authenticated source checks remain maintainer-only and
  must use explicitly authorized accounts without placing their data in release
  evidence.

## Update or install

Existing alpha installations should use Study Buddy's in-app update prompt once
this prerelease is public. A manual installation over an older alpha preserves
local app state.

Download files only from this GitHub release and compare the selected binary's
SHA-256 value with the attached `SHA256SUMS` before launching it.

On Windows PowerShell:

```powershell
Get-FileHash .\Study-Buddy-0.1.0-alpha.3-x64.exe -Algorithm SHA256
```

Uninstall through **Settings → Apps → Installed apps → Study Buddy**. The
uninstaller removes the application and its shortcuts while retaining local
Study Buddy state and the separately installed Codex provider to avoid
accidental data loss.

On Linux:

```bash
sha256sum Study-Buddy-0.1.0-alpha.3-x86_64.AppImage
chmod u+x Study-Buddy-0.1.0-alpha.3-x86_64.AppImage
./Study-Buddy-0.1.0-alpha.3-x86_64.AppImage
```

GitHub-generated source archives omit submodule contents. Clone recursively for
a source installation:

```bash
git clone --recurse-submodules https://github.com/HabsaTheDog/StudyBuddy.git
cd StudyBuddy
npm ci
```
