# Study Buddy showcase

Place the final non-sensitive outputs used in the demo here so judges can inspect them without portal credentials or rebuilding the application.

Recommended final contents:

```text
showcase/
|-- study-buddy-sample-guide.pdf
|-- study-buddy-interactive-guide.html
|-- study-buddy-interface.png
`-- SOURCES_AND_PERMISSIONS.md
```

## Acceptance checklist for every artifact

- The underlying source is synthetic, owned by Alvaro, openly licensed with attribution, or covered by express redistribution permission.
- The artifact contains no credentials, cookies, tokens, account identifiers, private URLs, personal calendar data, student records, real schedules, or room assignments.
- It contains no third-party logo, protected interface screenshot, or copyrighted course material without permission.
- PDF metadata and visible content have been reviewed.
- HTML works offline and does not make network requests.
- Filenames are short, descriptive, and in English.
- `SOURCES_AND_PERMISSIONS.md` explains the origin and permission for each example.

Do not copy an artifact directly from `study-buddy-data/` or `output/` without completing this review.
